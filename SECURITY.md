# Security Policy

## Supported Versions

Only the latest release is supported. A fix ships as a new tag; older tags are not patched.

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |

## Reporting a Vulnerability

Report vulnerabilities through GitHub's **private vulnerability reporting** — open the repository's
**Security** tab and choose **Report a vulnerability** (or go directly to
`/security/advisories/new`). Please do not open a public issue for a security problem.

Include the version or commit, the steps you took, what happened, and the impact you see. You can
expect an initial acknowledgement, and then either a fix or a written assessment once the report has
been reproduced. Credit is offered on request.

There is no security email address; GitHub is the only reporting channel.
